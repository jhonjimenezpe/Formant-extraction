# Extración de formantes 1 y 2 (estilo Formant Ceiling Optimization)
Este script automatiza la extracción de los formantes F1 y F2 del 40% central  de vocales etiquetadas en un TextGrid. Su principal innovación metodológica es intentar replicar la implementación de un método de "Optimización de Techo Formántico" (Formant Ceiling Optimization), inspirado teóricamente en Escudero et al. (2009)
